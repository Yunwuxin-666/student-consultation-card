# [YYYYMMDD] [学员真实姓名]｜建弦转行咨询卡

## 1. 标题与咨询信息

[用一小段完整自然句交代：学历专业与毕业阶段；当前在职、待业、在校或求职状态；已做过的工作/项目和相关工具；目标岗位与目标城市；可投入时间、预算或其他确实影响方案的条件。按已核实事实取舍，不要把这些字段机械排成“专业｜年限｜城市”。一般写3—5句；信息较多时可分两段。]

咨询日期：[日期]　咨询导师：[导师姓名]
资料来源：[咨询记录](妙记链接)

## 2. 核心结论

- [目前需要完成的主要准备，说明要做出什么具体内容。]
- [有必要时保留后续方向或关键结论，否则删除。]

## 3. 当前卡点

2. **[相邻方向]。** [保留导师建议的顺序与条件。没有则删除。]
